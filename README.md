# SGrifas — GitHub Pages
Versão estática em HTML/CSS/JavaScript, compatível com GitHub Pages.

## Publicar
1. Remova os arquivos PHP antigos do repositório (ou use outra branch/pasta).
2. Coloque `index.html` e a pasta `assets` na raiz do repositório.
3. Em Settings > Pages, publique a branch principal pela raiz (`/`).

## Importante
Esta versão é uma demonstração: campanhas, pedidos e números ficam no `localStorage` do navegador. Não há banco de dados, login seguro ou processamento de pagamentos. Para operação multiusuário é necessário um backend externo.
